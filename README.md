# Workout Tracker

Simple Python console application for tracking workouts.

## Description

Workout Tracker is a console application written in Python that allows users to manage their workouts.

The application supports adding, displaying, editing and deleting workouts.
Data is stored locally in a JSON file.

## Features

- Add workouts
- Display workouts
- Edit workouts
- Delete workouts
- Data is stored locally in SQLite database
- Input validation
- Modular project structure

## Technologies

- Python 3
- JSON
- Git
- SQLite

src/

## How to Run

Clone the repository:

```bash

git clone https://github.com/smakowski2005/workout-tracker-python
```

```
python src/main.py
```
